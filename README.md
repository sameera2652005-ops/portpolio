# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built using **HTML5, CSS3, and JavaScript**. This portfolio showcases my skills, projects, education, experience, and achievements in a clean and professional design. It is optimized for desktop, tablet, and mobile devices, providing a seamless user experience across all screen sizes.

## Features

* Responsive and mobile-friendly design
* Modern and professional UI/UX
* Hero section with introduction
* About Me section
* Skills with animated progress bars
* Experience and education timeline
* Interactive project showcase
* Certifications and achievements
* Contact section with social media links
* Smooth scrolling and navigation
* Dark/Light mode toggle
* CSS animations and hover effects
* Easy to customize and maintain

## Technologies Used

* HTML5
* CSS3
* JavaScript
